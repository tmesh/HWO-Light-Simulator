# HWO Light Simulator (HWOLS)

## Goals

- **Realistic data:** Simulate HWO observations (in all modes) as realistically as possible.
- **Community involvement:** Make HWO-like data openly available so the broader community can contribute.
- **Test algorithms:** Evaluate how existing post-processing methods perform on HWO (10^-10) data.
- **Develop algorithms:** Provide datasets for the community to develop their post processing algorithms.
- **Post-processing gain:** Quantify the post-processing gain factor, a key input to HWO yield estimates and design trades.
- **Data challenge:** Support a community HWO data challenge built on these simulations.
